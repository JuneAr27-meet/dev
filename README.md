# The Computer Inside Your Computer 💻

## About the Project
The Computer Inside Your Computer is an interactive desktop simulation built using Python and the Flet framework.

The application allows users to explore a virtual computer with different apps, windows, and hidden surprises.

## Features
- **Virtual Desktop:** A computer-like interface with a wallpaper and clickable icons.
- **folders and apps:** They are clickable and display a window with options.
- **Profile:** A user profile with an avatar.
- **Calculator:** A working calculator supporting addition, subtraction, multiplication, and division.
- **Secret Feature:** A hidden Easter egg that users can discover by experimenting with the calculator.

## Technologies Used
- Python
- Flet

## How to Run the App

1. Make sure Python is installed.
2. Install Flet using the terminal:

   `pip install flet`

3. Download the project files, including the `assets` folder.
4. Run the Python file:

   `python main.py`

## How to Use
1. Open the application to view the virtual desktop.
2. Click on any desktop icon to open its window.
3. Use the calculator to perform mathematical operations.
4. Explore the application to discover hidden features.
5. Close windows using the X button.
